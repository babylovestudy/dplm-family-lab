## 数据来源与 HMM 标准

UniProtKB 来源版本为 **2026_03**，响应头发布日为 **2026-09-02**。查询为：

```text
(xref:pfam-PF00194) AND (length:[180 TO 256]) AND (fragment:false)
```

[查询页面](https://www.uniprot.org/uniprotkb?query=%28xref%3Apfam-PF00194%29%20AND%20%28length%3A%5B180%20TO%20256%5D%29%20AND%20%28fragment%3Afalse%29)的数据会随数据库更新。复现这一快照时，应检查 `frozen-splits.json` 中的 accession 和序列 SHA-256。

使用 [Pfam PF00194](https://www.ebi.ac.uk/interpro/entry/pfam/PF00194/) 的 [官方 HMM](https://www.ebi.ac.uk/interpro/api/entry/pfam/PF00194?annotation=hmm)：模型 **PF00194.27**，长度 **255**，模型内的 sequence / domain GA 阈值均为 **27 bits**。至少一个独立 domain 还需覆盖 ≥80% 的模型位置，即至少 204 个位置；多个短 domain 的覆盖率不会相加。4,360 条清洗序列均通过 GA，其中 1,418 条未满足覆盖要求。

## 精确比对、聚类与审计

相似度采用 Biopython 全局最优比对，match = 1、mismatch = −1、gap open = −2、gap extend = −0.5。双方按序列 SHA-256 规范方向，比对得分相同时采用第一个最优解。

- identity = 相同残基数 / 全部比对列数，分母包含内部和末端 gap。
- 两侧 coverage 分别为“双侧都含残基的比对列数 / 各自完整序列长度”。
- identity ≥80%，且两侧 coverage 均 ≥80% 的配对建立连接；按传递连通分量整体划分数据。
- 长度比例和二肽多重集上界仅排除数学上不可能达标的配对，剩余必要配对用精确全局比对判断。

2,942 条序列共有 **4,326,211** 对；安全上界排除 4,155,491 对，实际精确计算 164,612 对，已有连通路径的 6,108 对省略冗余计算。记录的 1,223 条合并边属于生成森林，不能解释为完整阈值图的全部边数。

跨集合审计检查 **1,470,588 对**，安全筛选后精确检查 **43,304 对**，发现 **0 个违规配对**。独立重跑和传输后的本机复核均通过，冻结清单哈希保持一致。

完整准备实测约 **198.91 秒**，其中连通分量计算约 **166.36 秒**。缓存完整时复用准备结果约 0.01 秒，独立缓存审计约 9.25 秒；这些时长不构成其他机器上的性能承诺。

## 证据能够支持的结论

HMM 阈值和覆盖率支持序列符合该家族的统计特征。催化活性、可表达性、稳定性与真实生物功能需要额外验证。跨集合检查的结论以这里明确给出的比对指标和阈值为限，远缘同源关系仍然存在。微调数据的独立划分也不能证明序列未出现在 DPLM 的预训练数据中。
