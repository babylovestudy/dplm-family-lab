# 12 周学习路线

主线问题：**对 PF00194 家族进行生成式继续训练，能否在不明显牺牲多样性、也不只复制训练序列的条件下，提高生成序列的家族特征命中率？** 不预设答案一定为“能”。

每周建议分配：原理与阅读 3–4 小时、自己编程和实验 5–7 小时、总结与答辩 2–4 小时。GPU 未就绪时先推进 CPU、数据和源码任务；不把等待下载或租用时间当作已经掌握知识。

| 周 | 知识目标 | 亲手实践 | 验收与产出 |
| --- | --- | --- | --- |
| 1 | FASTA、氨基酸字母表、数组、batch/length 维度、梯度直觉 | 按 [第一周任务](week01.md) 创建环境；运行并修改 notebook；自己统计序列 | 独立解释形状、PAD/MASK 区别；交一页学习日志和练习答案 |
| 2 | Python 函数、文件、异常、配置、命令行；Git 的提交与差异 | 将自己写的 FASTA 统计逻辑整理成函数；故意加入非法字母并定位错误；运行 CPU demo | 不依赖复制，说明每个输入、输出和异常；解释 demo 为什么不能用于科研结论 |
| 3 | PF00194、全长蛋白与结构域、UniProt 记录、HMM、同源关系 | 获取正式快照；阅读筛选前后记录；解释长度与覆盖限制；核对来源和时间 | 提交数据卡，能解释每个排除条件，以及筛选偏差 |
| 4 | 聚类拆分、近重复、测试集、数据泄漏、统计单位 | 运行 prepare-data 与 audit-data；核对 ID、序列、cluster 和跨拆分近邻；锁定快照 | 能区分精确重复、80/80 相似性和远同源；审计不通过不进入正式训练 |
| 5 | Transformer、embedding、attention、logits、交叉熵 | 阅读模型与去噪损失源码；在 CPU 小张量上追踪 shape；画训练流程 | 口头追踪 FASTA→tokens→mask→logits→loss→梯度；解释不是自回归逐字续写 |
| 6 | 离散扩散、随机时间步、掩码率、特殊 token、迭代采样 | 准备远程环境；加载原始150M模型；做少量生成和固定噪声去噪评估 | 记录模型版本、实际 GPU、峰值显存与耗时；解释去噪指标不等于真实序列 perplexity |
| 7 | 继续训练、优化器、学习率、梯度累积、混合精度、检查点 | 先跑20个优化步；检查可训练参数、梯度、权重变化；尝试恢复短训练 | 必须有编码器更新和恢复记录；遇OOM能先减batch而非偷偷截断数据 |
| 8 | 验证集选模型、过拟合、小数据适配 | 在固定训练/验证拆分上跑受限步数；最多少量事先记录的学习率试验 | 选择规则写在看测试结果之前；保留原始模型与最优检查点，解释训练/验证趋势 |
| 9 | 公平生成对照、长度混杂、随机种子、计算预算 | 原始与适配模型复用长度列表、种子、采样参数和样本数；先完成一对正式对照 | 两组输入条件可逐项比较；失败与非法样本计入分母；不挑选“好看”序列 |
| 10 | HMM命中、覆盖率、序列多样性、最近邻、记忆与新颖性 | 完成生成集评估；结合最近训练邻居检查高分序列；再做已约定的重复种子 | 结果包含各指标分母、每次运行、区间与失败；能解释“家族特征”与“酶活”区别 |
| 11 | 复现、自动测试、数据/模型卡、工程交付 | 从干净环境复现CPU和一个小GPU回合；请他人按README检查；整理错误案例 | 提交可运行版本、最小例子、依赖记录、数据来源；用真实日志填写报告 |
| 12 | 技术表达、岗位映射、简历事实核查 | 做10分钟项目介绍和10分钟追问；完善开源仓库、实验报告及简历段落 | 自己解释所有关键实现；每个数字能定位到产物；写下一项有依据的后续改进 |

## 节奏调整

如果第4周数据不足、聚类不成立或工具不可用，先解决数据问题并记录原因，不用合成数据冒充 PF00194。如果第7周无法在实际GPU完成短训练，缩小batch或先固定可行的训练规模，重新估算预算；不要提前承诺跑完1000步。12周内宁可交付一个可信的小实验，也不要罗列未执行的大规模能力。

岗位探索贯穿第2、6、12周：各保存几个雇主官方职位，区分算法研究、ML工程、科学计算与数据岗位；使用 [求职证据模板](career-evidence.md)，不要把高级岗位全部要求当作一个入门项目必须完成的清单。
